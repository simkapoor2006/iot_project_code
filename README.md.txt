# IoT Fire Detection System

An IoT-based fire detection and alarm system developed using ESP32 and Firebase for real-time monitoring and alert generation.

## Features
- Detects fire using flame sensors
- Triggers buzzer/alarm on detection
- Real-time monitoring using Firebase
- Wi-Fi enabled IoT system using ESP32

## Technologies Used
- ESP32
- Arduino IDE
- Firebase
- Embedded C/C++
- IoT

## Components Used
- ESP32
- Flame Sensor
- Temperature sensor
- Smoke sensor
- Buzzer
- Jumper Wires
- Breadboard

## Project Description
This project is designed to improve fire safety by detecting flames and generating instant alerts. The flame sensor continuously monitors the surroundings, and when fire is detected, the buzzer is activated and the data is updated in Firebase for real-time monitoring through the internet using ESP32.
